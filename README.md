# Blog · 블로그 자동 작성

네이버 블로그 상품·서비스 글을 사진과 함께 자동으로 만드는 단일 페이지 도구입니다.
서버·데이터베이스 없이 GitHub Pages에서 바로 동작하며, 사용하는 기기에서 Claude API 키만 한 번 넣으면 됩니다.

## 파일
- `index.html` — 간편 버전 (기본 화면)
- `classic.html` — 이전 상세 버전 (경쟁 글 분석·목표 사양·Word 내보내기 등)

## 처음 설정 (기기마다 1회)
1. GitHub Pages 주소로 접속합니다. 예: `https://hbshin1020-coder.github.io/Brog/`
2. 오른쪽 위 **API 미연결** 버튼 → Claude API 키 붙여넣기 → 연결 테스트 → 저장
3. 맥북과 데스크톱에서 각각 한 번씩 입력합니다. 키는 그 브라우저에만 저장되고 GitHub에는 올라가지 않습니다.

## 사용 순서
1. 기본 정보: 상품명, 키워드(쉼표 구분), 글 유형
2. 소스: 참고 글 URL(자동 분석) 또는 직접 입력, 광고 구분, 작성 기준
3. 미디어: 사진·영상 1~20개를 끌어다 놓기
4. 4개 항목이 모두 ✓가 되면 **제작하기**
5. 결과를 바로 고친 뒤 **네이버용 복사** 또는 **PDF로 다운받기**, 끝나면 **Blog** 로고 또는 **처음으로 돌아가기**
