# Blog · 블로그 자동 작성 (v3.2)

잘 쓴 블로그 글을 참고해, 고른 목적에 맞는 새 글과 사진 배치를 네이버 정책에 맞게 만드는 단일 페이지 도구입니다.
서버 없이 GitHub Pages에서 동작하며, 기기마다 Claude API 키만 한 번 넣으면 됩니다.

## v3.2 추가 기능
- 글 분량 빠른 선택: 기본(자동) · 2,000자 · 4,000자 · 6,000자 · 그 이상(6,500~15,000자 직접 입력) — `CONFIG.LENGTHS`에서 수정

## v3.1 추가 기능
- 글 유형 12가지(정보 제공·문제 해결·제품 비교·구매 가이드·후기·시공 사례·트렌드·전문가 칼럼·질문답변·스토리텔링·지역 검색·프로모션) + 기타 — 유형별 구성 흐름 자동 적용
- 3번 「더 강조하고 싶은 게 있다면?」(선택, ▼로 펼침): 7가지 품질 기준 중 하나 강조 · 블로그 운영 목적 · 참고 글 · 메모
- 결과에 7가지 기준 자체 평가표(35점) — 자동 점수, 클릭해 직접 수정
- 권장 콘텐츠 비율(40/30/20/10) 대비 지금까지 쓴 글 현황과 다음 추천 유형

## 사용법 (3단계)
1. **상품명·키워드·사진**을 넣습니다. (참고 글·메모는 선택)
2. **글 품질**(경제/표준/고품질)을 고르고 **제작하기** — 예상 시간·비용이 미리 표시됩니다.
3. 결과를 확인·수정한 뒤 **제목/본문/태그 복사** 또는 **PDF**.

## 설정 바꾸기 (index.html 안의 `CONFIG` 한 곳)
| 바꾸고 싶은 것 | CONFIG 항목 |
|---|---|
| 모델·가격·품질 단계 | `MODELS`, `DEFAULT_MODEL` |
| 글 유형 추가/수정 | `TYPES` (이름·목적·구성 흐름·지시) |
| 강조 기준·운영 목적·권장 비율 | `EMPHASIS`, `GOALS`, `MIX` |
| 기본 분량 | `LENGTH` |
| 사진·캡처 한도, 전송 크기(비용) | `LIMITS`, `IMAGE` |
| 금지 표현·후기 위장 표현 | `BANNED`, `FAKE_REVIEW` |
| 광고 표기·안내 문구 | `AD_NOTICE`, `DISCLAIMER`, `MEMO_FORM` |
| AI 작성 규칙 | `SYSTEM` |
고친 뒤 `VERSION` 숫자를 올리면 새 버전이 열렸는지 로고 옆에서 확인할 수 있습니다.

## 비용 (2026-10 기준 단가)
- 경제 Haiku 5.5: 입력 $0.10 / 출력 $0.50 (100만 토큰당)
- 표준 Sonnet 5.5: $2 / $10 · 고품질 Opus 5.5: $4 / $20
- 사진은 512px로 줄여 보내고, 참고 글은 구조만 보내며, 캡처는 800px·최대 8조각으로 제한합니다.
